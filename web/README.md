# Bend It Right

Real-time **workout repetition counting** (MediaPipe Pose) and **yoga pose timing**
(YOLO11s-pose fine-tuned on yoga poses). CSC-340 Artificial Intelligence course project.

Team: Akari Kyaw Thein, Ant Bone Kyaw, Han Win Aung, Nay Chi Lin Lei, Thaw Zin Moe Myint.

- **Workout Tracker:** Push Up, Curl Up, Jumping Jack, Squat.
- **Yoga Detection:** Goddess, Plank, Tree, Warrior II, with a timer for how long each pose is held.

Everything runs in the visitor's browser (ONNX Runtime Web and MediaPipe Tasks), so camera video never leaves the device.

Source code: https://github.com/thompson129/Bend-It-Right
